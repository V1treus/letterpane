# Support / Поддержка / Підтримка

Use this repository's **Issues → New issue → Bug report** for reproducible bugs. Russian, Ukrainian and English are welcome. Include the version from Settings → Data, Windows version, display scale, package type and steps to reproduce. If possible, reproduce the problem in `--demo` mode with 10, 100 or 500 fictional accounts.

Never attach refresh/access tokens, import lists, `Letterpane Portable.data`, `.data`, vault files or personal mail. Use demo screenshots. For security reports, read [SECURITY.md](SECURITY.md).

Letterpane is in preview. Response times vary.

Об ошибках сообщайте через GitHub Issues. Можно писать по-русски, по-украински или по-английски. Укажите версию Letterpane, Windows, масштаб экрана, тип сборки и шаги. По возможности воспроизведите ошибку в деморежиме. Используйте вымышленные ящики и примеры.

Про помилки повідомляйте через GitHub Issues. Можна писати українською, російською або англійською. Укажіть версію Letterpane, Windows, масштаб екрана, тип збірки й кроки. За можливості відтворіть помилку в деморежимі. Використовуйте вигадані скриньки та приклади.
