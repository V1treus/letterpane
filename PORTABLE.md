# Letterpane Portable 1.3.9

Переносимая версия Letterpane для управления профилем до 500 ящиков.

Для запуска нужен один файл **dist/Letterpane Portable 1.3.9.exe**. Его можно скопировать в отдельную папку и запустить двойным щелчком. Устанавливать Node.js или Python и распаковывать архив вручную не нужно.

В EXE размером около 37 МиБ находится собственный Node.js. При первом запуске компоненты извлекаются в `%TEMP%/LetterpanePortable/<хэш-сборки>` и занимают примерно 100 МиБ. Следующие запуски используют готовый кэш.

Новый профиль создаётся рядом с EXE в папке `Letterpane Portable.data`. Там находятся зашифрованное хранилище токенов и профиль WebView2. При переносе EXE вместе с аккаунтами перенесите также папку профиля. DPAPI привязывает ключ к исходной учётной записи Windows. На другом компьютере может потребоваться повторный импорт.

При обновлении положите Letterpane рядом со старым EXE. Если там есть `Posta Portable.data`, Letterpane откроет этот профиль на месте. Если присутствуют обе папки профиля, приложение выберет `Letterpane Portable.data`. Перед обновлением закройте старую версию и сохраните резервную копию профиля.

Русский, английский и украинский переключаются в настройках оформления. Выбор сохраняется в профиле. Файлы `ui-language` и `ui-theme` рядом с ним содержат только код языка и название темы для окон запуска. В старом профиле файл темы создаётся при первом запуске этой версии; последующие запуски используют его с самого начала.

Для демонстрации без аккаунтов:

```powershell
& '.\Letterpane Portable 1.3.9.exe' --demo
```

Требования прежние: Windows x64, .NET Framework 4.8 и системный Microsoft Edge WebView2 Runtime. Первый запуск требует свободного места во временной папке и права записи рядом с EXE. Установщика, автозагрузки и изменений реестра нет.

В демонстрации доступны 10, 100 и 500 вымышленных ящиков; сетевых запросов к Microsoft нет. Можно проверить темы, таблицу, поиск, группы и массовые действия. Демоизменения исчезают при закрытии.

Для сборки из исходников выполните `npm run build:single`. Сборщик использует каталог `.build/portable-payload-1.3.9`, исключает пользовательские профили из ресурсов и проверяет, что предыдущие EXE и архивы сохранились.
